# Example

This plugin was created for the RuneLite client environment. It offers Quality of Life features not addressed by others. With this plugin, when you select an alchemy spell, your inventory will be highlighted indicating the spell will be cast if you select an item. We found this plugin would be useful to avoid alching hard-to-acheive items.
